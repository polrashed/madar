# نیت و نوا

اپ Flutter فارسی برای فال حافظ، خواندن فایل TXT شعرهای هرمزگان، علاقه‌مندی‌ها و خوانش صوتی فارسی.

## اجرا
1. Flutter SDK نسخهٔ سازگار با Dart 3.3+ نصب کنید.
2. در پوشهٔ پروژه `flutter pub get` و سپس `flutter run` را اجرا کنید.
3. برای Android، Flutter هنگام آماده‌سازی مسیر SDK را در `android/local.properties` تنظیم می‌کند.

وابستگی‌های اصلی در pubspec.yaml با نسخهٔ ثابت درج شده‌اند. دریافت محتوای آنلاین به اتصال اینترنت نیاز دارد؛ در حالت آفلاین فال‌های نمونهٔ تعبیه‌شده در اپ قابل استفاده‌اند.
